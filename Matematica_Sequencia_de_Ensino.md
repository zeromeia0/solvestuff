# Matemática — Sequência de ensino (do básico ao 12.º ano)

> Ordem recomendada para ensinar os tópicos de `Matematica_Topicos_Basico_e_Secundario.md`. O ensino básico segue a ordem **cálculo numérico → frações → percentagem → álgebra essencial → geometria → estatística**. Dentro de cada bloco, cada tópico só depende do que vem antes. Os códigos entre parênteses (B…, S…) remetem para as secções do documento principal.

## Notas

- Os decimais ficam no bloco das frações porque décimas e centésimas são frações; a percentagem vem logo a seguir porque depende dos dois.

- Tópicos assinalados com **AE2018** ou **AE2023** aplicam-se apenas aos alunos do respetivo programa.
